# ThaLab · 地中海贫血本科生科研团队

广西医科大学 **ThaLab（Thalassemia Lab）** 本科生科研团队 —— 团队课题与成果总览。

> 广西是我国地中海贫血高发区。团队围绕该病的发病机制、产前筛查与干预策略开展研究，
> 依托广西地中海贫血防治重点实验室开展工作，由 **侯伟** 副教授指导。

## 页面内容

`index.html` 是一个**完全自包含的单文件页面**——logo、校徽、导师照片、34 张团队照片、
论文全文 PDF 全部内联，**没有任何外部依赖**，下载下来双击就能看。

| 板块 | 说明 |
|---|---|
| 导师介绍 | 指导教师简介与研究方向 |
| 研究方向词云 | 词频取自团队全部课题与项目的题目，字号越大代表该方向项目越多（可点击，跳到对应课题） |
| 团队风采 | 团队日常工作照片 |
| 统计概览 | 各类别逐年分布 + 年度趋势折线图 |
| 团队情况总览 | 课题项目 / 获奖情况 / 软件著作权 / 论文 四张明细表 |
| 成果展览 | 最新获奖、最新项目与最新论文（**点论文标题可在新标签页打开全文 PDF**） |

---

## 关于个人信息的说明

本页为**对外公开版**，经脱敏处理：

- **不包含团队成员的个人信息** —— 姓名、学号、联系方式、学院等一律未收录；
- 仅保留指导教师（导师）一人的介绍；
- 课题、获奖、软著、论文只展示**成果本身**（题目、级别、编号、期刊、DOI 等公开信息），不含完成人名单。
